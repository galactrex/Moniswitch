# Official repository policy

Moniswitch is authored, maintained, and released by Galactrex.

Bug reports and feature requests are welcome through the repository's issue
forms. External pull requests, unsolicited code submissions, generated patches,
and third-party release uploads are not accepted into the official repository.
This keeps authorship, review, signing, and release responsibility in one place.

## Report a problem

Before opening an issue:

1. use the latest official build;
2. search existing issues;
3. reproduce the problem once with the smallest relevant setup;
4. remove private data from every field, log excerpt, and screenshot;
5. describe what happened, what should have happened, and the exact steps.

Never attach settings files, private keys, certificates, full logs, crash dumps,
or raw network output. Replace addresses, usernames, machine names, paths,
serial numbers, device identifiers, and fingerprints with clear placeholders.

## Request a feature

Describe the actual setup and the result that would help. Product-shaped facts
are more useful than a paragraph asking for everything to become automatic.

## Forks

The MIT License permits forks and modifications as long as its notice remains.
Forks and third-party builds are not official Moniswitch releases and must not
claim endorsement by Galactrex.
